# 第二大脑

这是你的第二大脑。现在它是一副空骨架，**往里放东西，它才开始变成你的。**

它不绑定任何软件，本质就是一个文件夹加一堆 Markdown 文件：没有数据库、没有账号、没有会员费。Claude Code、Codex、Cursor、Obsidian，甚至记事本，都能打开它。换工具不用搬家。

## 几个区，放什么

| 区 | 放什么 |
|---|---|
| `收集箱/` | 别人的东西：链接、图片、摘录。先收进来，不整理 |
| `灵感箱/` | 你自己的东西：想法、选题、也许以后会做的事 |
| `项目区/` | 在做的事。进行中、已完成、已归档 |
| `创作区/` | 你写的东西。未发布、已发布 |
| `学习思考区/` | 正在消化的学习输入 |
| `生活区/` | 健康、家庭、孩子、旅行 |
| `知识库/` | 沉淀。经验总结 → 方法论 → skills，三层往上升 |

每个放东西的文件夹里都有一份「○○怎么用.md」，点开就知道那里放什么。

## 三份关键文件

| 文件 | 管什么 |
|---|---|
| `AGENTS.md` | 你的规矩和触发词，让 AI 听你的。完整规则只有这一份 |
| `SOUL.md` | 你是谁，让 AI 懂你 |
| `CLAUDE.md` | 不用管。有些 AI 工具只认这个文件名，它只负责指向 `AGENTS.md` |

## 怎么打开

| 你用 | 怎么办 |
|---|---|
| Claude Code | 终端进入这个文件夹，输入 `claude` |
| Codex | 终端进入这个文件夹，输入 `codex` |
| Cursor、Windsurf 等 | 「打开文件夹」选中这个文件夹 |
| Obsidian | 「打开文件夹作为仓库」选中这个文件夹，看着更舒服 |
| 网页版 AI | 每次新对话把 `AGENTS.md` 的内容粘到开头，AI 给的内容你自己存进对应文件夹 |

## 头一个月怎么用

- **每天**：想到什么就说「记录 ……」，看到好东西就说「收藏 ……」。不整理，先收。
- **做完一件事**：说一句「总结」，AI 会把教训追加进 `知识库/经验总结/`。
- **每周挑个时间**：翻一遍这周的经验总结。同一类事反复出现三次，就说「写成 skill」。

拿不准放哪，就放收集箱。不要为了归类卡住，卡住就不记了，不记等于没有。

> 第二大脑不是设计出来的，是用出来的。用满 30 天，你会有完全不同的感受。
