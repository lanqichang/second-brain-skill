# Skill 六格模板

> **用法**：复制这份文件 → 改名成你的 skill 名字（比如 `写客户跟进消息.md`，**不带日期**）
> → 放在这个文件夹里 → 六格填满 → **让 AI 真跑一次**。
>
> 不知道怎么下笔？先看旁边那份填满的范例：`示例-写客户跟进消息.md`。
