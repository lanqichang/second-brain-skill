# 第二大脑 · Second Brain Skill

> 对 AI 说一句「安装第二大脑」，它会问你想装在哪个文件夹，然后把一套给 AI 用的个人知识库搭好。

第二大脑就是一个文件夹加一堆 Markdown 文件。没有数据库，没有账号，没有会员费。里面有一份规则文件 `AGENTS.md`，AI 每次开工都先读它，所以你不用每次重新交代「我是谁、东西放哪儿、什么不许做」。

这套结构是作者自己每天在用的那一套，去掉了个人内容，留下了骨架和规则。

## 它解决什么问题

- **和 AI 聊完，什么都没留下。** 半小时聊出来的思路，两周后要从头再讲一遍。
- **东西越存越乱。** 链接、想法、草稿、笔记混在一起，要用的时候找不到。
- **每个 AI 都不认识你。** 换一个工具、开一个新对话，就要重新自我介绍。

装好之后，你说「记录」，想法进灵感箱；说「收藏」，链接进收集箱；做完一件事说「总结」，教训追加到经验文件里。同一类事做过三次，就把它写成 skill，以后不用再教第二遍。

## 安装

需要一个能读写本地文件的 AI 工具（Claude Code、Codex、Cursor 等）和 Python 3。

**方式一：让 AI 帮你装（推荐）**

把下面这句话发给你的 AI：

```
帮我安装这个 skill：https://github.com/lanqichang/second-brain-skill
装好后运行它，帮我安装第二大脑。
```

**方式二：自己装**

```bash
git clone https://github.com/lanqichang/second-brain-skill ~/.claude/skills/second-brain
```

然后打开 Claude Code，说一句：**安装第二大脑**。

用其他工具的话，把仓库 clone 到任意位置，对 AI 说「请读这个文件夹里的 SKILL.md，按它帮我安装第二大脑」。

## 安装过程是什么样的

大约 5 分钟，全程对话，不需要你敲命令：

1. **AI 问你装在哪儿。** 它会列出几个推荐位置（Mac 上首选 iCloud 云盘，多台设备自动同步），你也可以自己指定。选 iCloud 的话，建议在访达里对这个文件夹选「保留下载」，免得文件被换成占位符后 AI 读不到。
2. **AI 把骨架装好**，告诉你建了哪些文件夹。已有的文件不会被覆盖。
3. **AI 问你三个问题**：怎么称呼你、最常让 AI 做哪三件事、什么是 AI 绝对不许碰的。它据此改好你的规则文件。
4. **当场试一次**：你随口说一个想法，亲眼看到它被存进灵感箱。

## 装好之后有什么

```
第二大脑/
├── AGENTS.md      你的规矩和触发词，AI 每次开工先读它
├── SOUL.md        你是谁，让 AI 写出来的东西像你
├── README.md      一页纸总览
├── 收集箱/        别人的东西：链接、图片、摘录
├── 灵感箱/        你自己的想法和选题
├── 项目区/        进行中、已完成、已归档
├── 创作区/        未发布、已发布
├── 学习思考区/    正在消化的学习输入
├── 生活区/        健康、家庭、孩子、旅行
└── 知识库/        经验总结 → 方法论 → skills，三层往上沉淀
```

## 几条设计原则

- **信任大于聪明。** AI 移动、删除、大改之前先告诉你，不静默动你的东西。
- **涌现式分类。** 不预先建一堆子文件夹。同一类攒够 5 份、靠搜才找得到了，再分。
- **三层沉淀，只能往上走。** 先有踩过的坑（经验总结），再抽出规律（方法论），最后写成 AI 能照做的说明书（skill）。
- **规则只有一份。** 所有规矩写在 `AGENTS.md`，上限 12KB。具体做法写进 skill，不往规则文件里堆。
- **不绑定工具。** 换模型、换客户端，文件夹还是那个文件夹。

## 常见问题

**装错位置了怎么办？** 在新位置再装一次。旧文件夹不会被自动删除，你自己处理。

**我已经有一个笔记文件夹，能装进去吗？** 能。安装器只补缺少的文件和文件夹，已有的一律不动。

**一定要用 Obsidian 吗？** 不用。Obsidian 只是一个好看的窗口，「打开文件夹作为仓库」选中第二大脑就行。

**隐私怎么保证？** 所有文件只在你自己的电脑上。需要注意的是，你让 AI 读某个文件时，内容会发给你正在用的那个模型，和你把文字贴进对话框是一回事。不想外传的资料单独放，并在 `AGENTS.md` 红线里写明不许读。

**Windows 能用吗？** 安装脚本只用 Python 标准库，按设计支持 Windows，但目前只在 macOS 上实测过。遇到问题欢迎提 Issue。
